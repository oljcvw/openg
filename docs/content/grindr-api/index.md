# Grindr API specification

Source audit: 2026.08.13 / Grindr Android v26.13.0 (170510)

Endpoint declarations are confirmed against the pinned, locally decoded APK
source snapshot. Static source proves that a client route and signature exist;
it does not prove current server availability, rollout state, or response
behavior. See [APK endpoint source index](./endpoint-source-index.md) for the
line-exact declaration inventory and [Application and service identifiers](./identifiers.md)
for public application codes, integration IDs, service hosts, and redacted
credential-field locations.
